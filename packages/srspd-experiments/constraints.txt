# Pins for reproducing published numbers with srspd-experiments.
#
#   pip install -c packages/srspd-experiments/constraints.txt 'packages/srspd-experiments[eval,muse]'
#
# The software stack is part of the experimental configuration: a different
# torch / transformers changes kernels, dtype promotion and tokenizer behaviour,
# and therefore logprobs, CE readouts and benchmark accuracies. The published
# numbers were produced on exactly these versions; results on any other stack
# are not numerically comparable to them.
#
# Tensor-parallel degree changes results too: TP changes the reduction order of
# the sharded matmuls and so perturbs logprobs. Two evaluations that are put in
# one table must share a TP size; every lm-eval result row records it
# (`tp` in srspd_experiments.results).

transformers==5.14.1
lm_eval==0.4.12
